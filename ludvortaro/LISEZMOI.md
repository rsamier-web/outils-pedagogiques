# Ludvortaro : installation sur GitHub Pages

1. Dans le dépôt `outils-pedagogiques`, créez un dossier `ludvortaro`.
2. Déposez-y tous les fichiers de ce dossier (index.html, manifest.webmanifest, sw-ludvortaro.js et les 4 images PNG).
3. Attendez une à deux minutes la publication, puis ouvrez :
   https://rsamier-web.github.io/outils-pedagogiques/ludvortaro/
4. Dans Chrome (Android) : menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Mise à jour : remplacez index.html, puis changez la valeur VERSION en haut de sw-ludvortaro.js
(par exemple ludvortaro-v3) pour que les appareils installés reçoivent la nouvelle version.
