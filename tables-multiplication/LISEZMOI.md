# Tables de multiplication : application installable

Adresse : https://rsamier-web.github.io/outils-pedagogiques/tables-multiplication/

Version pour un seul utilisateur (sans profils), avec une série de jours d'entraînement :
objectif 5 jours par semaine, 2 jours de repos possibles par semaine sans perdre la série.
L'outil d'origine (avec profils, pour l'orthophoniste) reste à la racine : tables_multiplication.html.

Installation dans Chrome :
- Ordinateur : bouton « Installer » dans la barre d'outils de l'application, ou icône « Installer » à droite de la barre d'adresse.
- Android : menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».
- iPhone (Safari) : Partager → « Sur l'écran d'accueil ».

Une fois installée, l'application fonctionne hors ligne. La progression est enregistrée sur l'appareil.

Mise à jour : remplacer index.html, puis changer la valeur VERSION en haut de sw-tables.js
(par exemple tables-v2) pour que les appareils installés reçoivent la nouvelle version.
