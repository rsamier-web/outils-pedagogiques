# Le marchand : application installable

Adresse : https://rsamier-web.github.io/outils-pedagogiques/marchand/

Installation dans Chrome :
- Ordinateur : icône « Installer » à droite de la barre d'adresse, ou bouton « Installer » dans la barre d'outils de l'application, ou menu ⋮ → « Caster, enregistrer et partager » → « Installer la page en tant qu'application ».
- Android : menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Une fois installée, l'application fonctionne hors ligne.

Mise à jour : remplacer index.html, puis changer la valeur VERSION en haut de sw-marchand.js
(par exemple marchand-v2) pour que les appareils installés reçoivent la nouvelle version.
