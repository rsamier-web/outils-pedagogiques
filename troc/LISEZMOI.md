# Le troc chez l'indienne : application installable

Adresse : https://rsamier-web.github.io/outils-pedagogiques/troc/

Jeu du troc en base 4 (coquillage 1, plume 4, pierre 16, fleur 64, feuille 256) :
règle du troc, J'échange, Je compte, Je troque, Je rends.

Installation dans Chrome :
- Ordinateur : icône « Installer » à droite de la barre d'adresse, ou bouton « Installer » dans la barre d'outils de l'application.
- Android : menu ⋮ → « Installer l'application ».

Mise à jour : remplacer index.html, puis changer la valeur VERSION en haut de sw-troc.js
(par exemple troc-v2) pour que les appareils installés reçoivent la nouvelle version.
