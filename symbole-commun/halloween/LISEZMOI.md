# Symbole commun · Halloween (sons « ch » et « j »)

Jeu du symbole commun (principe du Dobble) : deux cartes rondes de 8 images, une seule image commune.
Le joueur clique sur l'image commune sur chacune des deux cartes. 57 pictogrammes ARASAAC sur le thème d'Halloween :
19 mots avec le son [ʃ] « ch », 19 mots avec le son [ʒ] « j / g », 19 mots sans ces sons.

- Application installable (PWA) avec Chrome sur ordinateur et téléphone, fonctionne hors ligne après la première visite.
- Génération des cartes : plan projectif d'ordre 7 (57 symboles, 57 cartes, 8 symboles par carte).
- Options : lecture du mot à voix haute, coloration des graphèmes ch / j / g, images inclinées.
- Imagier des 57 mots, bilan de fin de partie (réussites, erreurs, mots trouvés par son).

Modifier le code : `source/src/` puis, dans `source/`, `npm install` et `node build.mjs`
(régénère `index.html` et `sw.js`).

Pictogrammes : Sergio Palao, ARASAAC (https://arasaac.org), Gouvernement d'Aragon, licence CC BY-NC-SA.
