# Ludlernejo Mineklonia — instalado ĉe GitHub Pages

1. En via deponejo (ekzemple `outils-pedagogiques`) kreu dosierujon `ludlernejo`.
2. Metu en ĝin ĉiujn dosierojn de ĉi tiu dosierujo.
3. Atendu unu aŭ du minutojn kaj malfermu: https://<uzantonomo>.github.io/<deponejo>/ludlernejo/
4. En Chrome (Androido): menuo ⋮ → «Instali la aplikaĵon».

Ĝisdatigo: anstataŭigu index.html kaj ŝanĝu la valoron VERSIO en sw-ludlernejo.js (ekzemple ludlernejo-v2).
